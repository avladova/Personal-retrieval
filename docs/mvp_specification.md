# MVP: персонализированный корпоративный поиск

## Назначение

Показать, как один и тот же запрос может приводить к различному порядку документов для разных сотрудников при сохранении единого хранилища и исходных прав доступа.

## Пользовательский сценарий

Пользователь выбирает профиль сотрудника, вводит запрос и сравнивает базовую и персонализированную выдачу. Для каждого результата показываются причины ранжирования.

## Данные

Демонстратор использует синтетические документы, профили пользователей и историю взаимодействий. Персональные или банковские данные не используются.

## Конвейер

1. Получить запрос и профиль пользователя.
2. Отфильтровать документы по доступам пользователя.
3. Рассчитать лексическую релевантность запроса.
4. Для персонализированной выдачи добавить признаки соответствия роли, подразделению и истории взаимодействий.
5. Отсортировать доступные документы и показать вклад признаков.

## Иллюстративная формула

`Score(d,u,q) = 0.50·TextRel(d,q) + 0.20·RoleFit(d,u) + 0.15·TeamFit(d,u) + 0.15·HistoryFit(d,u)`

Все признаки нормированы в диапазон [0, 1]. Коэффициенты являются параметрами демонстратора, а не обученными или валидированными весами. Базовая выдача сортирует доступные документы только по `TextRel`.

## Разграничение доступа

Проверка доступа выполняется до ранжирования. Документ, на который у пользователя нет прав, не должен попадать ни в базовую, ни в персонализированную выдачу. Персонализация не меняет ACL и не создаёт новых разрешений.

## Что не входит в MVP

- подключение к реальным корпоративным системам;
- SSO и синхронизация прав доступа;
- индексация полнотекстовых документов промышленного масштаба;
- поиск по эмбеддингам и генерация ответов LLM;
- автоматическое обучение весов;
- промышленный мониторинг и аудит.

## Следующий этап проверки

Подготовить набор реальных, обезличенных запросов и релевантных документов, согласовать метрики (например, nDCG@k, Recall@k, MRR), сравнить базовый и персонализированный варианты и отдельно провести проверку безопасности разграничения доступа.
