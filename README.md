# Персонализированный корпоративный поиск

Демонстратор проекта **«Сервис персонализированного виртуального индекса корпоративного хранилища»** для обсуждения в контексте акселератора «Газпромбанк.Тех».

## Что показывает MVP

- поиск по демонстрационному набору корпоративных документов;
- сравнение обычного ранжирования с персонализированным;
- влияние роли сотрудника, подразделения и истории взаимодействий;
- объяснение факторов, повлиявших на позицию документа;
- фильтрацию по правам доступа до ранжирования.

Данные демонстрационные и синтетические. Это не интеграция с реальным хранилищем и не оценка промышленной точности модели.

## Быстрый запуск

Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run demo/app.py
```

## Сценарий демонстрации

1. Выберите пользователя и сформулируйте запрос, например «лимиты кредитного риска».
2. Сравните базовую выдачу и персонализированную выдачу.
3. Откройте объяснение ранжирования: роль, подразделение, недавние взаимодействия и текстовая релевантность.
4. Проверьте, что документы вне разрешённого пользователю набора не появляются в результатах.

## Принципиальные ограничения

- Персонализация влияет на порядок доступных документов, но не расширяет права доступа.
- Веса факторов заданы как параметры демонстратора и не являются результатом эмпирической калибровки.
- Поиск реализован на прозрачном лексическом сходстве, без заявления о полноценном семантическом поиске на эмбеддингах.
- Для промышленного внедрения потребуются подключение к корпоративным источникам, проверка модели разграничения доступа, оценка качества на размеченных запросах и аудит.
